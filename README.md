## 📖 About

FleetRentAPI is a backend system for managing car rentals and vehicle maintenance operations. It handles booking cars, tracking maintenance schedules, and managing fleet data, built following **Clean Architecture** principles for a scalable and maintainable codebase.

---

## 🏗️ Architecture

This project follows **Clean Architecture**, separating concerns into independent layers:

**Dependency Rule**: Inner layers (Domain) know nothing about outer layers (Api). All dependencies point inward.

---

## 🛠️ Tech Stack

- **ASP.NET Core** — Web API framework
- **C#** — Primary language
- **Entity Framework Core** — ORM / Data access
- **Clean Architecture** — Project structure & design pattern

---

## ✨ Features

- 🚙 Vehicle fleet management
- 📅 Car rental booking system
- 🔧 Maintenance tracking & scheduling
- 🏢 Clean separation between business logic and infrastructure
